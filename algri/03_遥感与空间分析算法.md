# 03. 遥感与空间分析算法

本节整理项目在 GEE API 无直接 OGE 映射时采用的主要 Python 原生实现。实现位于 `gee_unmatched_functions.py`，以 NumPy、SciPy 和可选的 scikit-image 为基础。

## 1. 像元数学与单位缩放

| 算法 | 对应 API | 计算 |
| --- | --- | --- |
| 指数变换 | `ee.Image.exp` | \( y=e^x \) |
| 矩阵乘法 | `ee.Image.matrixMultiply` | \( C=A \times B \)（`numpy.matmul`） |
| 单位缩放 | `ee.Image.unitScale` | \( y=(x-low)/(high-low) \) |
| Landsat TOA 简化定标 | `ee.Algorithms.Landsat.TOA` | \( y=DN\times0.0001 \) |

注意：单位缩放的现有实现未对 `high == low` 特判；TOA 定标为通用简化系数，不替代依据卫星元数据进行的严谨辐射定标。

## 2. 统计归约与邻域分析

### 2.1 多波段/数组归约

`ee.Image.reduce` 将给定轴上的值按 `mean`、`sum`、`max`、`min`、`median`、`std`、`var` 或非零计数归约：

\[
y = R(x, axis)
\]

其中 `R` 为所选统计函数。集合归约还提供最大值、最小值、均值、中位数和计数等操作。

### 2.2 邻域均值和总和

`ee.Image.reduceNeighborhood` 使用 `scipy.ndimage.uniform_filter` 计算大小为 \(k\times k\) 的局部窗口统计：

\[
mean(i,j)=\frac{1}{k^2}\sum_{(u,v)\in W_{ij}}x(u,v)
\]

总和通过 `local_mean × k²` 得到。现有实现支持 `mean` 与 `sum`，其他 reducer 保持原图不变。

## 3. 连通域像元计数

对应 `ee.Image.connectedPixelCount`。先对非零像元执行连通域标记，再把同一连通域面积赋给区域内每个像元：

\[
result(p)=\min(|C_p|, max\_size)
\]

支持两种邻域：

- 8 连通：3×3 全 1 结构元；
- 4 连通：上下左右相邻结构元。

实现使用 `scipy.ndimage.label`。输入应先是二值或掩膜影像；若直接输入连续值，所有非零像元均会参与连通判断。

## 4. Canny 边缘检测

对应 `ee.Algorithms.CannyEdgeDetector`：

1. 首选 `skimage.feature.canny`；
2. 参数 `sigma` 控制高斯平滑尺度；
3. 高阈值为 `threshold`，低阈值为 `0.5 × threshold`；
4. 若没有 scikit-image，则退化为 Sobel 梯度幅值阈值检测：

\[
G=\sqrt{(\partial I/\partial x)^2+(\partial I/\partial y)^2},\quad edge=(G>threshold)
\]

Sobel 退化路径不包含 Canny 的非极大值抑制和双阈值滞后连接，因此仅作兼容性兜底。

## 5. DEM 地形因子

对应 `ee.Terrain.products`，由 Sobel 梯度估计坡度、坡向和简化山体阴影：

\[
slope=\arctan(\sqrt{dx^2+dy^2})\times\frac{180}{\pi}
\]

\[
aspect=atan2(dy,-dx)\times\frac{180}{\pi}
\]

其中负坡向角被归一化到 \([0,360)\)。现有山体阴影为固定 45° 光照角的简化余弦模型。由于未传入像元大小、坐标系和真实太阳方位/高度角，该实现适合演示和迁移验证，不应直接作为高精度地形产品。

## 6. 随机影像与数组处理

- `ee.Image.random`：产生均匀分布 `U(0,1)` 或标准正态分布 `N(0,1)` 随机栅格；支持种子复现。
- `ee.Image.arraySlice`：沿指定轴使用 NumPy 切片提取子数组。
- `ee.Image.arraySort`：沿指定轴排序。
- `ee.Image.arrayGet`：按索引提取数组值。
- `ee.Image.argmax` / `argmin`：返回指定轴最大/最小元素的索引。

## 7. 分类与精度评价

`ee.Classifier.amnhMaxent` 当前实现为分类器配置对象（保存特征、标签、类别字段和输出格式），并未完成 MaxEnt 参数训练或概率预测。`ee.ConfusionMatrix.consumersAccuracy` 则基于混淆矩阵按列计算消费者精度；实际使用时应先确认矩阵行列的“真实类别/预测类别”约定。
