## 🟡 警告问题（20 个）

### 分类一：Filter 映射到非 Filter（10 个）

这些映射功能有相似之处，但**使用方式不同**：
- GEE Filter 返回 Filter 对象，用于 `fc.filter(filter)`
- OGE 直接操作数据，如 `Coverage.eq()` 或 `FeatureCollection.filterBounds()`

| # | GEE API | OGE API | 差异说明 |
|---|---|---|---|
| 1 | `ee.Filter.and` | `Coverage.and` | Filter 逻辑组合 → 像元逻辑运算 |
| 2 | `ee.Filter.bounds` | `FeatureCollection.filterBounds` | Filter → 直接方法调用 |
| 3 | `ee.Filter.calendarRange` | `FeatureCollection.filterDate` | 需要日期解析转换 |
| 4 | `ee.Filter.contains` | `Feature.contains` | Filter → 单要素方法 |
| 5 | `ee.Filter.date` | `FeatureCollection.filterDate` | Filter → 直接方法调用 |
| 6 | `ee.Filter.eq` | `Coverage.eq` | Filter 条件 → 像元比较 |
| 7 | `ee.Filter.gt` | `Coverage.gt` | Filter 条件 → 像元比较 |
| 8 | `ee.Filter.gte` | `Coverage.gte` | Filter 条件 → 像元比较 |
| 9 | `ee.Filter.lt` | `Coverage.lt` | Filter 条件 → 像元比较 |
| 10 | `ee.Filter.not` | `Coverage.not` | Filter 否定 → 像元否定 |
| 11 | `ee.Filter.or` | `Coverage.or` | Filter 逻辑组合 → 像元逻辑运算 |

**修正建议**：这些映射在实际使用中需要转换调用方式，详见下文。

## 📝 修正方案

### 方案一：Python 实现（适用于严重问题）

```python
"""修正严重问题的 Python 实现"""

# 1. ee.Feature.set()
def feature_set(feature, key, value):
    """设置 Feature 的属性值"""
    result = feature.copy()
    result[key] = value
    return result

# 2. ee.FeatureCollection.geometry()
def feature_collection_geometry(collection):
    """获取要素集合中所有要素的几何对象"""
    return [f.geometry() for f in collection]

# 3. ee.FeatureCollection.sort()
def feature_collection_sort(collection, property_name, ascending=True):
    """对要素集合按属性排序"""
    return sorted(collection, 
                  key=lambda f: f.get(property_name, 0), 
                  reverse=not ascending)

# 4. ee.Filter.withinDistance()
def filter_within_distance(collection, target, distance):
    """集合级距离过滤器"""
    return [f for f in collection 
            if f.withinDistance(target, distance)]

# 5. ee.Image.and() - 逻辑与
def logical_and(image1, image2):
    """逻辑与运算"""
    import numpy as np
    return np.where((image1 != 0) & (image2 != 0), 1, 0)

# 6. ee.Image.rgbToHsv()
def rgb_to_hsv(r, g, b):
    """RGB 转 HSV"""
    r, g, b = r / 255.0, g / 255.0, b / 255.0
    max_val = max(r, g, b)
    min_val = min(r, g, b)
    diff = max_val - min_val
    
    # 色相
    if diff == 0:
        h = 0
    elif max_val == r:
        h = (60 * ((g - b) / diff) + 360) % 360
    elif max_val == g:
        h = (60 * ((b - r) / diff) + 120) % 360
    else:
        h = (60 * ((r - g) / diff) + 240) % 360
    
    # 饱和度
    s = 0 if max_val == 0 else diff / max_val
    
    # 明度
    v = max_val
    
    return h, s, v
```
